## Summary for the build
- A void with floating voxel masses, not a floor or landscape. No ground, no horizon.
- Everything on a diagonal grid, so silhouettes step like stairs.
- Backlit: sky brighter than the structures. Near = dark, far = lighter and dissolving into fog.
- Thin wireframe box chains running diagonally, sparse dust specks.
- Hue can shift with depth: indigo/teal near the top, dusk-pink/magenta toward the core.
